# Financial Habit Builder

## Project Overview
Financial Habit Builder is a web application designed to help users track income, expenses, savings goals, financial habits, and wealth growth.

## Technology Stack
- Frontend: React, Vite, Bootstrap, Chart.js
- Backend: Node.js and Express
- Database: MongoDB Atlas
- Version Control: Git and GitHub

## Main Features
- Dashboard with financial summaries
- Income and expense tracking
- Savings goals and progress tracking
- Habit tracking
- Wealth analytics
- User authentication and protected routes
- Admin functionality
